# QuantaInstitute

**Open research, mathematical computing primitives, and applied machine learning experiments.**

QuantaInstitute develops inspectable computational frameworks and reproducible research notebooks focused on tensor mathematics, automatic differentiation, and data systems.

### Core Repositories
* **[nexora](https://github.com/QuantaInstitute/nexora)** — Lightweight, inspectable machine learning framework for tensor computation, automatic differentiation, and neural networks.
* **[notebooks-gallery](https://github.com/QuantaInstitute/notebooks-gallery)** — Curated cookbook of practical ML, LLM, RAG, evaluation, and AI systems notebooks.
