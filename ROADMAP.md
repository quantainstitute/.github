# QuantaInstitute Roadmap

QuantaInstitute focuses on **computational foundations, mathematical software, and reproducible applied ML research**.

## Active Repositories (Phase 1)
* **[nexora](https://github.com/QuantaInstitute/nexora)** — Lightweight, inspectable machine learning framework for tensor computation, automatic differentiation, and neural networks.
* **[notebooks-gallery](https://github.com/QuantaInstitute/notebooks-gallery)** — Curated cookbook of practical ML, LLM, RAG, evaluation, and AI systems notebooks.

## Planned Repositories (Phase 2)
* **`nexora-vision`** — Modular vision and sequence model architecture extensions built on Nexora.
* **`autograd-bench`** — Numerical gradient verification and computational graph profiling suite.
* **`synthetic-data-lab`** — Statistical and programmatic dataset generation methods for controlled ML experimentation.

## Future Exploration (Phase 3)
* Probabilistic programming primitives, symbolic-numeric hybrid solvers, and technical whitepapers accompanied by executable code.
